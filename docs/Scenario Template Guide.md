# Scenario Template Guide

## Guidelines
1. All content must be **self-contained**: everything should be explained **within the game**, no need for outside sources.  
2. Include **Introduction, Theory, Practice, Revision, and End/Wrap-Up scenes**.  
3. Theory and practice **can follow each other in steps**; they do not need to be strictly sequential.  
4. Provide **side panels** for notes, tips, and additional in-game explanations.  
5. Use **icons, arrows, and visual cues** to enhance interactivity.  
6. Include **interactive exercises**: drag-and-drop, multiple choice, fill-in-the-blank and simulations.  
7. Include **end-of-module summary in dialogue form**, highlighting learning objectives and rewards.

## Device Security Example

### Scene 0 – Introduction
- **Background / Scene:** Office background  
- **Characters:** Manager, IT Assistant  
- **Dialogue / Narrative:**  
  - `Manager: "Welcome aboard! Before you start configuring laptops, let’s talk about Device Security."`  
  - `IT Assistant: "Sure! What exactly does that mean?"`  
  - `Manager: "Device Security means protecting computers and other digital devices from unauthorized access or data loss. We focus on three pillars: Locking, Encryption, and Backups."`  
  - `IT Assistant: "Got it!"`  
- **Interactive Instructions:** Press space to continue  
- **UI Elements / Icons:** Neon character, arrows, info panel  
- **Side Panel Content:** Introduce Device Security pillars with full in-game explanations  

---

### Scene 1 – Theory / Explanation
- **Background / Scene:** Laptop illustration with lock icons  
- **Characters:** Manager, IT Assistant  
- **Dialogue / Narrative:**  
  - `Manager: "First, Locking: set strong passwords, PINs, or biometrics. Screens should lock automatically."`  
  - `IT Assistant: "So it keeps intruders out?"`  
  - `Manager: "Exactly! Next, Encryption: it turns files into unreadable code. And finally, Backups: restore files after accidents or malware."`  
- **Interactive Elements:** Click icons to reveal explanations  
- **Icons / Visuals:** Lock icon, encryption key icon, backup cloud icon  
- **Side Panel Content:** Full definitions of Locking, Encryption, Backups  

---

### Scene 2 – Practice / Application
- **Background / Scene:** Company laptop setup interface  
- **Characters:** Manager, IT Assistant  
- **Dialogue / Narrative:**  
  - `Manager: "Secure Alex's new laptop before handing it over."`  
- **Interaction Type:** MCQs  
- **Prompt / Instructions:** What is the first step before handing over a company laptop?  
- **Options:**  
  1. Install programs  
  2. Personalize desktop  
  3. Copy data from another computer  
  4. Set strong password and enable encryption  
- **Correct Answer:** 4  
- **Hints / Guidance:** Always secure device first  
- **Icons / Visuals:** Lock, shield, checkmark  
- **Side Panel Content:** Explain why device security must come before other tasks  

---

### Scene 3 – Revision / Summary
- **Background / Scene:** Visual recap of laptop with icons  
- **Characters:** Manager, IT Assistant  
- **Dialogue / Narrative:**  
  - `Manager: "Let’s review key points: Locking, Encryption, Backups, and Incident Response."`  
- **Interaction / Quiz:** Drag actions to correct categories  
- **Feedback / Notes:** Show correct grouping in real-time  
- **Icons / Visuals:** Lock, encryption key, cloud, alert  
- **Side Panel Content:** Step-by-step review of all actions  

---

### Scene X – End / Wrap-Up
- **Dialogue / Narrative:**  
  - `Manager: "Well done! You’ve completed Device Security training."`  
  - `IT Assistant: "Thanks! I’ve learned how to keep devices and data safe."`  
  - `Manager: "Summary: Secure first, use strong passwords, encrypt data, back up regularly."`  
- **Interactive Elements:** Badge unlock: 🎖️ “Device Security Awareness”  
- **Icons / Visuals:** Trophy, confetti  
- **Side Panel Content:**  
  **Learning Objectives Recap:**  
  1. Identify and enable important locking settings  
  2. Understand why encryption is valuable  
  3. Design a simple and effective backup plan  
  4. Combine multiple protections for maximum safety
