Android Components

Click each component to learn what it does

Activity

A screen the user interacts with. Every visible page in your app is typically an Activity. It has its own lifecycle.

Service

Background work without a UI. Keeps running even when user switches apps. Useful for syncing data, streaming music.

Broadcast Receiver

Listens for and reacts to system-wide or app-level events. Android wakes it up when a relevant event fires, like low battery or device boot.

Content Provider

Manages and exposes structured data to other apps in a controlled, secure way. Other apps request data through it, not around it.

AndroidManifest.xml

Every component must be declared here. The Manifest is the blueprint Android reads at install time.

  • <activity> Screens users see
  • <service> Background workers
  • <receiver> Event listeners
  • <provider> Data gatekeepers
